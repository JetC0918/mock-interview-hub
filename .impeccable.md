## Design Context

### Users
CodioLive serves interviewers and candidates running collaborative coding interviews, plus guests who want to observe an ongoing session without creating an account. The guest viewing experience should make the interview easy to follow while remaining clearly read-only.

### Brand Personality
Focused, technical, and confident. The interface should feel live and capable without becoming distracting or theatrical.

### Aesthetic Direction
Preserve CodioLive's existing dark technical interface, teal primary accent, compact workspace layout, and code-first visual hierarchy. Live status should be obvious, while spectator controls stay quiet and secondary.

### Design Principles
1. Put the ongoing interview content ahead of navigation and decoration.
2. Make spectator mode unmistakably read-only and accessible without sign-in.
3. Use live indicators and session context sparingly to reinforce real-time activity.
4. Preserve the existing CodioLive component patterns, density, and dark palette.
5. Keep core viewing usable across desktop and smaller screens.
